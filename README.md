# Forsure 🧑‍🏫

> **Learn it. Understand it. Know it.**

Forsure is an AI programming teacher designed to teach software development from absolute zero.

It does not treat learning like watching a course or copying answers. Forsure explains concepts with familiar real-world objects, stories, visualizations, examples, guided practice, and Socratic questions—then checks whether the learner actually understands.

## Vision

Build a personal teacher that can take someone from:

**"I don't know how to code."**

to:

**"I can build software myself."**

The first focus is **Python**, starting with complete beginners.

## Teaching philosophy

1. Start with something the learner already understands.
2. Turn abstract concepts into concrete objects, stories, and visual examples.
3. Connect the real-world idea to actual code.
4. Let the learner experiment.
5. Ask the learner to predict what will happen.
6. Check reasoning, not just whether the answer is correct.
7. Detect misconceptions.
8. Re-explain using a different approach when needed.
9. Re-test understanding later.
10. Increase difficulty only when the learner is ready.

### Example

Instead of:

> "A variable is a named reference to a value stored in memory."

Forsure might teach:

> "Imagine a box with a label on it. We can put something inside the box and use its label to find it again."

Then connect the idea to:

```python
apples = 3
```

The learner sees the concept, interacts with it, writes the code, and explains what the code does.
